# Learn module scope

Type: grilling
Status: resolved

## Question

The current scaffold has a standalone "Learn" section (guided learning modules, quizzes, `mockModules`) separate from species browsing. Is that in scope for this effort?

## Answer

No — the standalone Learn module (guided lessons, quizzes) is out of scope; ruled out rather than resolved as a route on the map. The underlying intent behind it was narrower: a "learn more about this species" experience — reading text and viewing photos for a single species. That's served instead by the in-scope Species detail view (ticket 10), not a separate learning-module system.
